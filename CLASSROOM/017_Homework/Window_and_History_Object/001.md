# 1. Window Object in JavaScript

## 1. What is the Window Object?

The `window` object is the global object in browser JavaScript. It represents the browser window or tab in which a webpage is running.

It provides different properties and methods to interact with the browser.

**In simple words:** Window object browser ki window ko represent karta hai. Iski help se hum browser ke features jaise alert, prompt, timers, document aur storage ko access kar sakte hain.

## 2. Why do we use the Window Object?

We use the Window object to interact with browser features.

**Common uses:**
- Display popup messages.
- Get browser window dimensions.
- Open a new browser window or tab.
- Set timers.
- Access the current webpage.
- Access Local Storage and Session Storage.
- Access browser history.

## 3. Important Properties of Window Object

| Property | Description |
|---|---|
| `window.innerWidth` | Returns the width of the browser's content area. |
| `window.innerHeight` | Returns the height of the browser's content area. |
| `window.outerWidth` | Returns the width of the browser window, including browser UI where applicable. |
| `window.outerHeight` | Returns the height of the browser window, including browser UI where applicable. |
| `window.document` | Provides access to the current HTML document. |
| `window.location` | Provides information about the current URL. |
| `window.history` | Provides access to the current tab's session history. |
| `window.localStorage` | Provides access to Local Storage. |
| `window.sessionStorage` | Provides access to Session Storage. |

### Example 1: Get Browser Width and Height

```javascript
console.log(window.innerWidth);
console.log(window.innerHeight);
```

**Output:**

```text
1366
768
```

*Note: These are example values. Actual output depends on your browser window size.*

- `innerWidth` returns the width of the content area.
- `innerHeight` returns the height of the content area.

### Example 2: Access the HTML Document

```javascript
console.log(window.document);
```

**Output:** Displays the current HTML document in the console.

**Important:** We can also write:

```javascript
console.log(document);
```

Both `window.document` and `document` refer to the same document in normal browser JavaScript.

## 4. Important Methods of Window Object

| Method | Description |
|---|---|
| `alert()` | Displays an alert message. |
| `confirm()` | Displays a confirmation popup. |
| `prompt()` | Takes input from the user. |
| `open()` | Opens a new browsing context. |
| `close()` | Attempts to close the current window. |
| `setTimeout()` | Executes a function once after a delay. |
| `setInterval()` | Executes a function repeatedly after an interval. |
| `clearTimeout()` | Cancels a scheduled timeout. |
| `clearInterval()` | Stops a scheduled interval. |

### Example 1: alert()

The `alert()` method displays a popup message.

```javascript
window.alert("Welcome to JavaScript!");
```

We can also write:

```javascript
alert("Welcome to JavaScript!");
```

**Output:**

A popup appears with the message:

```text
Welcome to JavaScript!
```

### Example 2: confirm()

The `confirm()` method displays a popup with OK and Cancel buttons.

It returns:
- `true` if the user clicks OK.
- `false` if the user clicks Cancel.

```javascript
let result = confirm("Are you sure you want to delete this item?");

console.log(result);
```

**Output:**

```text
true
```

*If the user clicks OK.*

**Real-life use:** Before deleting a record, we can ask the user for confirmation.

### Example 3: prompt()

The `prompt()` method takes input from the user through a popup.

```javascript
let name = prompt("Enter your name:");

console.log(name);
```

**Output:**

```text
Umesh
```

*If the user enters Umesh.*

**Important:**
- If the user clicks OK, it returns the entered value as a string.
- If the user clicks Cancel, it returns `null`.

### Example 4: setTimeout()

The `setTimeout()` method executes a function once after a specified delay.

**Syntax:**

```javascript
setTimeout(function, delay);
```

**Example:**

```javascript
setTimeout(function() {
    console.log("Hello Umesh!");
}, 3000);
```

**Output after approximately 3 seconds:**

```text
Hello Umesh!
```

Here:
- `3000` means 3000 milliseconds.
- 1000 milliseconds = 1 second.
- The function executes only once.

### Example 5: setInterval()

The `setInterval()` method executes a function repeatedly after a specified time interval.

```javascript
setInterval(function() {
    console.log("Hello JavaScript!");
}, 2000);
```

**Output:**

```text
Hello JavaScript!
Hello JavaScript!
Hello JavaScript!
```

The message is printed approximately every 2 seconds until the interval is stopped.

### Example 6: clearInterval()

The `clearInterval()` method stops a previously started interval.

```javascript
let count = 1;

let timer = setInterval(function() {

    console.log(count);

    count++;

    if (count > 5) {
        clearInterval(timer);
    }

}, 1000);
```

**Output:**

```text
1
2
3
4
5
```

**Explanation:**
1. Initially, `count` is 1.
2. Every second, the value is printed.
3. After printing 5, the condition becomes true.
4. `clearInterval(timer)` stops the interval.

### Example 7: clearTimeout()

The `clearTimeout()` method cancels a timeout before it executes.

```javascript
let timer = setTimeout(function() {
    console.log("Hello JavaScript!");
}, 3000);

clearTimeout(timer);
```

**Output:**

```text
No output
```

Because we cancelled the timeout before the function executed.

## 5. Important Concept: Window is a Global Object

In browser JavaScript, the Window object is the global object.

Many of its properties and methods can be accessed directly without writing `window`.

**Example:**

```javascript
window.alert("Hello");
```

We can also write:

```javascript
alert("Hello");
```

Both work in normal browser scripts.

# 2. History Object in JavaScript

## 1. What is the History Object?

The `history` object is a property of the Window object. It allows us to interact with the session history of the current browser tab.

Session history contains navigation entries visited in that tab.

**In simple words:** History object ki help se hum browser ke Back aur Forward buttons ki tarah navigation kar sakte hain.

**Example:**

Suppose a user visits these pages:

```text
Home → About → Contact
```

If the user is currently on Contact, we can use the History object to navigate back to About.

## 2. Why do we use the History Object?

We use the History object to:

- Navigate to the previous page.
- Navigate to the next page.
- Reload the current page using `history.go(0)`.
- Move to a specific position in session history.
- Manage navigation in Single Page Applications (SPAs).

## 3. Important Properties of History Object

| Property | Description |
|---|---|
| `history.length` | Returns the number of entries in the current tab's session history. |
| `history.state` | Returns the state associated with the current history entry. |

### Example 1: history.length

```javascript
console.log(history.length);
```

**Example Output:**

```text
3
```

*Note: The actual value depends on the current tab's session history.*

It tells us the number of session history entries.

### Example 2: history.state

```javascript
console.log(history.state);
```

**Output:**

```text
null
```

It may return `null` if no state has been associated with the current history entry.

## 4. Important Methods of History Object

| Method | Description |
|---|---|
| `history.back()` | Navigates to the previous history entry. |
| `history.forward()` | Navigates to the next history entry. |
| `history.go()` | Navigates a specified number of steps backward or forward. |
| `history.pushState()` | Adds a new entry to session history without reloading the page. |
| `history.replaceState()` | Updates the current history entry without reloading the page. |

### Example 1: history.back()

The `back()` method navigates to the previous history entry.

```javascript
history.back();
```

**Example:**

```text
Home → About → Contact
```

If we are on Contact and execute `history.back()`, we navigate to About.

### Example 2: history.forward()

The `forward()` method navigates to the next history entry, if one exists.

```javascript
history.forward();
```

**Example:**

If we are on About and Contact is the next history entry, executing `history.forward()` navigates to Contact.

### Example 3: history.go()

The `go()` method allows us to move a specified number of steps backward or forward.

**Move one step backward:**

```javascript
history.go(-1);
```

**Move one step forward:**

```javascript
history.go(1);
```

**Reload the current page:**

```javascript
history.go(0);
```

**Remember:**

- Negative number = Backward.
- Positive number = Forward.
- Zero = Reload current page.

### Example 4: history.pushState()

The `pushState()` method adds a new entry to the browser's session history without reloading the page.

**Syntax:**

```javascript
history.pushState(state, title, url);
```

**Example:**

```javascript
history.pushState(
    { page: "about" },
    "",
    "/about"
);
```

**Explanation:**

- First argument: State object containing information.
- Second argument: Title (currently ignored by browsers).
- Third argument: New URL.

**What happens?**

- A new history entry is added.
- The URL changes to `/about`.
- The page does not automatically reload.
- JavaScript must handle displaying the appropriate page content.

### Example 5: history.replaceState()

The `replaceState()` method updates the current history entry instead of adding a new entry.

**Syntax:**

```javascript
history.replaceState(state, title, url);
```

**Example:**

```javascript
history.replaceState(
    { page: "home" },
    "",
    "/home"
);
```

**What happens?**

- The current history entry is updated.
- The URL changes to `/home`.
- No new history entry is added.
- The page does not automatically reload.

## 5. Difference Between pushState() and replaceState()

| pushState() | replaceState() |
|---|---|
| Adds a new history entry. | Updates the current history entry. |
| Increases the history length by one. | Does not add a new history entry. |
| Used when navigating to a new application route. | Used when updating the current route or its state. |

# 3. Difference Between Window Object and History Object

| Window Object | History Object |
|---|---|
| Represents the browser window. | Represents the current tab's session history. |
| It is the global object in browser JavaScript. | It is a property of the Window object. |
| Provides access to browser features. | Provides methods for browser navigation. |
| Example: `alert()`, `prompt()`, `setTimeout()`. | Example: `back()`, `forward()`, `go()`. |

## 4. Relationship Between Window and History

The History object is available as a property of the Window object.

```javascript
window.history.back();
```

We can also write:

```javascript
history.back();
```

Both work in normal browser JavaScript.

# 5. Important Interview Questions

### Q1. What is the Window object in JavaScript?

The Window object is the global object in browser JavaScript. It represents the browser window and provides access to browser features such as alerts, timers, document, and storage.

### Q2. What is the History object?

The History object allows us to interact with the session history of the current browser tab.

### Q3. What is the difference between setTimeout() and setInterval()?

- `setTimeout()` executes a function once after a specified delay.
- `setInterval()` executes a function repeatedly after a specified interval.

### Q4. What is the difference between alert(), prompt(), and confirm()?

- `alert()` displays a message.
- `prompt()` takes input from the user.
- `confirm()` asks for confirmation and returns `true` or `false`.

### Q5. What is the difference between pushState() and replaceState()?

- `pushState()` adds a new entry to browser history.
- `replaceState()` updates the current history entry.

### Q6. What does history.go(-1) do?

It navigates one step backward in the current tab's session history.

### Q7. Can we access the History object without writing window?

Yes. We can use `history` directly because it is available as a global browser property.

### Q8. Does pushState() reload the webpage?

No. It changes the URL and adds a new history entry without automatically reloading the page.

# 7. Important Notes for Freshers

- `window` is the global object in browser JavaScript.
- `document` is a property of the Window object.
- `history` is also a property of the Window object.
- `setTimeout()` executes only once.
- `setInterval()` executes repeatedly until stopped.
- `clearTimeout()` cancels a timeout.
- `clearInterval()` stops an interval.
- `pushState()` adds a new history entry.
- `replaceState()` updates the current history entry.
