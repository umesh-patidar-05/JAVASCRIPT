# 1. Local Storage in JavaScript

## 1. What is Local Storage?

Local Storage is a feature of the browser that allows us to store data in the form of **key-value pairs**.

- Data is stored inside the user's browser.
- Data remains saved even after closing the browser.
- Data does not automatically expire.
- Data is stored as strings.

**In simple words:** Local Storage is used to save data in the browser so that it remains available even after refreshing the page or closing the browser.

## 2. Why do we use Local Storage?

Suppose a user visits a website and selects Dark Mode.

If we don't use Local Storage, the selected theme might reset when the user refreshes the page.

But if we save the theme in Local Storage, the website can remember the user's preference.

**Common use cases:**
- Saving user preferences (Dark/Light Mode).
- Remembering language selection.
- Saving shopping cart data.
- Remembering website settings.

## 3. Important Local Storage Methods

| Method | Description |
|---|---|
| `localStorage.setItem()` | Stores data |
| `localStorage.getItem()` | Retrieves data |
| `localStorage.removeItem()` | Removes a specific item |
| `localStorage.clear()` | Removes all stored data |
| `localStorage.key()` | Returns the key at a given index |

## 4. Examples

### Example 1: Store Data using setItem()

```javascript
localStorage.setItem("username", "Umesh");
localStorage.setItem("age", "20");
```

Here:
- `"username"` is the key.
- `"Umesh"` is the value.

### Example 2: Get Data using getItem()

```javascript
let name = localStorage.getItem("username");

console.log(name);
```

**Output:**
```text
Umesh
```

### Example 3: Remove Specific Data

```javascript
localStorage.removeItem("username");
```

This removes only the `username` key and its value.

### Example 4: Clear All Data

```javascript
localStorage.clear();
```

This removes all data stored by the website in Local Storage.

## 5. Practical Example: Remember Dark Mode

```javascript
// Store theme
localStorage.setItem("theme", "dark");

// Get theme
let theme = localStorage.getItem("theme");

console.log(theme);
```

**Output:**
```text
dark
```

## 6. Important: Local Storage stores only strings

If we want to store an object or array, we need `JSON.stringify()` and `JSON.parse()`.

**Example:**

```javascript
let user = {
    name: "Umesh",
    age: 20
};

// Convert object into string
localStorage.setItem("user", JSON.stringify(user));

// Convert string back into object
let data = JSON.parse(localStorage.getItem("user"));

console.log(data.name);
console.log(data.age);
```

**Output:**
```text
Umesh
20
```

- `JSON.stringify()` converts a JavaScript object into a JSON string.
- `JSON.parse()` converts a JSON string back into a JavaScript value.

# 2. Session Storage in JavaScript

## 1. What is Session Storage?

Session Storage is a browser feature that allows us to store data in key-value pairs for a particular browser tab session.

- Data is stored inside the browser.
- Data remains available after refreshing the page.
- Data is removed when that tab or window's session ends.
- Different tabs have separate Session Storage.
- Data is stored as strings.

**In simple words:** Session Storage is used to store temporary data. When the particular tab session ends, its data is automatically cleared.

## 2. Why do we use Session Storage?

Suppose a user is filling out a form with multiple steps.

We want to temporarily save the information so that if the user refreshes the page, the entered information is not lost.

We can use Session Storage for this purpose.

**Common use cases:**
- Temporary form data.
- Multi-step form information.
- Temporary checkout information.
- Storing temporary user activity.

## 3. Important Session Storage Methods

Session Storage uses the same methods as Local Storage.

| Method | Description |
|---|---|
| `sessionStorage.setItem()` | Stores data |
| `sessionStorage.getItem()` | Retrieves data |
| `sessionStorage.removeItem()` | Removes a specific item |
| `sessionStorage.clear()` | Removes all stored data |
| `sessionStorage.key()` | Returns the key at a given index |

## 4. Examples

### Example 1: Store Data

```javascript
sessionStorage.setItem("username", "Umesh");
sessionStorage.setItem("course", "JavaScript");
```

### Example 2: Get Data

```javascript
let name = sessionStorage.getItem("username");

console.log(name);
```

**Output:**
```text
Umesh
```

### Example 3: Remove Specific Data

```javascript
sessionStorage.removeItem("username");
```

### Example 4: Clear All Data

```javascript
sessionStorage.clear();
```

## 5. Practical Example: Temporary Form Data

```javascript
// Store user information
sessionStorage.setItem("username", "Umesh");

// Retrieve user information
let name = sessionStorage.getItem("username");

console.log(name);
```

**Output:**
```text
Umesh
```

The data remains available even after refreshing the page, but normally disappears when the tab session ends.

# 3. Difference Between Local Storage and Session Storage

| Local Storage | Session Storage |
|---|---|
| Stores data until manually removed. | Stores data for a tab session. |
| Data remains after closing and reopening the browser. | Data is removed when the tab session ends. |
| Data can be shared across tabs of the same origin. | Each tab has its own separate storage. |
| Used for long-term preferences. | Used for temporary data. |
| Usually around 5–10 MB, depending on the browser. | Usually around 5–10 MB, depending on the browser. |

## 4. Quick Practical Comparison

```javascript
// Local Storage
localStorage.setItem("name", "Umesh");

// Session Storage
sessionStorage.setItem("name", "Umesh");
```

Both store the same value, but their lifetimes are different.

# 5. Important Interview Questions

**Q1. What is Local Storage in JavaScript?**

Local Storage is a browser storage mechanism that allows us to store key-value pairs. Its data remains available even after closing the browser until it is manually removed.

**Q2. What is Session Storage?**

Session Storage is a browser storage mechanism that stores data for a particular tab session. Its data is removed when that session ends.

**Q3. Does Local Storage store objects directly?**

No. Local Storage stores strings. We use `JSON.stringify()` to convert objects into strings and `JSON.parse()` to convert them back.

**Q4. What is the difference between Local Storage and Session Storage?**

The main difference is data lifetime. Local Storage persists until manually removed, whereas Session Storage is limited to a tab session.

**Q5. Does refreshing the page remove Session Storage data?**

No. Session Storage data remains available even after refreshing the page.

**Q6. Are Local Storage and Session Storage secure for storing passwords?**

No. Sensitive information such as passwords, authentication tokens, and private data should not be stored in browser storage because JavaScript running on the page can access it.
