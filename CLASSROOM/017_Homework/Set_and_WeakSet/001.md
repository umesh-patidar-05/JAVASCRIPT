# 1. Set in JavaScript

## 1. What is a Set?

A `Set` is a built-in JavaScript object that is used to store a collection of unique values.

**Unique means:** Duplicate values are not allowed in a Set.

If we try to add the same value multiple times, Set stores it only once.

**In simple words:** Set ek collection hota hai jisme hum unique values store karte hain. Agar same value multiple times add karenge, toh Set usse sirf ek baar store karega.

### Example 1: Creating a Set

```javascript
let numbers = new Set([10, 20, 30, 40]);

console.log(numbers);
```

**Output:**

```text
Set(4) {10, 20, 30, 40}
```

Here, we created a Set containing four unique values.

### Example 2: Duplicate Values in Set

```javascript
let numbers = new Set([10, 20, 10, 30, 20, 40]);

console.log(numbers);
```

**Output:**

```text
Set(4) {10, 20, 30, 40}
```

**Explanation:**

- 10 appears two times, but Set stores it only once.
- 20 appears two times, but Set stores it only once.
- 30 and 40 are also stored.

**Important:** Set maintains the insertion order of its values.

## 2. Why do we use Set?

We use Set when:

- We want to store unique values.
- We want to remove duplicates from an array.
- We want to check whether a value exists.
- We want to add or delete values easily.
- We want to perform operations on collections of unique values.

**Real-life example:**

Suppose a website has a list of students who registered for an event.

Some students may register more than once due to repeated actions.

We can use Set to store each student only once.

## 3. How to Create a Set?

There are two common ways to create a Set.

**Method 1: Empty Set**

```javascript
let mySet = new Set();

console.log(mySet);
```

**Output:**

```text
Set(0) {}
```

**Method 2: Set with Initial Values**

```javascript
let mySet = new Set([1, 2, 3, 4]);

console.log(mySet);
```

**Output:**

```text
Set(4) {1, 2, 3, 4}
```

## 4. Important Methods of Set

| Method | Description |
|---|---|
| `add()` | Adds a new value to the Set. |
| `delete()` | Removes a value from the Set. |
| `has()` | Checks whether a value exists. |
| `clear()` | Removes all values. |
| `size` | Returns the number of unique values. |
| `forEach()` | Executes a function for every value. |
| `values()` | Returns an iterator containing Set values. |
| `keys()` | Also returns an iterator of Set values. |
| `entries()` | Returns an iterator containing `[value, value]` pairs. |

### Example 1: add()

The `add()` method is used to add a new value to a Set.

```javascript
let numbers = new Set();

numbers.add(10);
numbers.add(20);
numbers.add(30);

console.log(numbers);
```

**Output:**

```text
Set(3) {10, 20, 30}
```

**Adding duplicate values:**

```javascript
let numbers = new Set();

numbers.add(10);
numbers.add(20);
numbers.add(10);

console.log(numbers);
```

**Output:**

```text
Set(2) {10, 20}
```

**Important:**

- `add()` adds a value if it is not already present.
- If the value already exists, Set remains unchanged.
- `add()` returns the same Set, so we can chain multiple `add()` calls.

### Example 2: delete()

The `delete()` method removes a specific value from a Set.

```javascript
let numbers = new Set([10, 20, 30, 40]);

numbers.delete(20);

console.log(numbers);
```

**Output:**

```text
Set(3) {10, 30, 40}
```

**Important:** `delete()` returns:
- `true` if the value was found and deleted.
- `false` if the value was not found.

```javascript
let numbers = new Set([10, 20, 30]);

console.log(numbers.delete(20));
console.log(numbers.delete(50));
```

**Output:**

```text
true
false
```

### Example 3: has()

The `has()` method checks whether a value exists in a Set.

```javascript
let fruits = new Set(["Apple", "Mango", "Banana"]);

console.log(fruits.has("Apple"));
console.log(fruits.has("Orange"));
```

**Output:**

```text
true
false
```

**Explanation:**

- Apple exists in the Set, so it returns `true`.
- Orange does not exist, so it returns `false`.

### Example 4: clear()

The `clear()` method removes all values from a Set.

```javascript
let numbers = new Set([10, 20, 30]);

numbers.clear();

console.log(numbers);
```

**Output:**

```text
Set(0) {}
```

### Example 5: size

The `size` property returns the total number of unique values in a Set.

```javascript
let numbers = new Set([10, 20, 10, 30, 20]);

console.log(numbers.size);
```

**Output:**

```text
3
```

**Remember:** Set uses `size`, not `length`.

### Example 6: forEach()

The `forEach()` method executes a callback function for every value in the Set.

```javascript
let fruits = new Set(["Apple", "Mango", "Banana"]);

fruits.forEach((value) => {

    console.log(value);

});
```

**Output:**

```text
Apple
Mango
Banana
```

### Example 7: values()

The `values()` method returns an iterator containing all Set values.

```javascript
let numbers = new Set([10, 20, 30]);

console.log(numbers.values());
```

**Output (conceptually):**

```text
SetIterator {10, 20, 30}
```

We can use `for...of` to access its values.

```javascript
let numbers = new Set([10, 20, 30]);

for (let value of numbers.values()) {

    console.log(value);

}
```

**Output:**

```text
10
20
30
```

### Example 8: keys()

The `keys()` method also returns an iterator containing Set values.

```javascript
let numbers = new Set([10, 20, 30]);

for (let value of numbers.keys()) {

    console.log(value);

}
```

**Output:**

```text
10
20
30
```

**Important:** In a Set, `keys()` and `values()` return the same values because a Set does not have separate keys and values.

### Example 9: entries()

The `entries()` method returns an iterator containing arrays in the form `[value, value]`.

```javascript
let numbers = new Set([10, 20, 30]);

console.log([...numbers.entries()]);
```

**Output:**

```text
[
    [10, 10],
    [20, 20],
    [30, 30]
]
```

**Why are both values the same?**

Because Set stores values, not key-value pairs like Map.

## 5. How to Convert an Array into a Set?

We can pass an array directly to the Set constructor.

```javascript
let numbers = [10, 20, 10, 30, 20, 40];

let uniqueNumbers = new Set(numbers);

console.log(uniqueNumbers);
```

**Output:**

```text
Set(4) {10, 20, 30, 40}
```

## 6. How to Remove Duplicates from an Array?

This is one of the most common uses of Set.

We can convert an array into a Set and then convert it back into an array.

```javascript
let numbers = [10, 20, 10, 30, 20, 40];

let uniqueNumbers = [...new Set(numbers)];

console.log(uniqueNumbers);
```

**Output:**

```text
[10, 20, 30, 40]
```

**Explanation:**

1. `new Set(numbers)` removes duplicate values.
2. The spread operator `...` extracts values from the Set.
3. Square brackets `[]` create a new array.

**Alternative using Array.from():**

```javascript
let numbers = [10, 20, 10, 30, 20];

let uniqueNumbers = Array.from(new Set(numbers));

console.log(uniqueNumbers);
```

**Output:**

```text
[10, 20, 30]
```

## 7. Important Concept: Set with Objects

Set can also store objects.

However, two objects with the same properties are still considered different if they have different references.

```javascript
let students = new Set();

students.add({ name: "Rahul" });
students.add({ name: "Rahul" });

console.log(students.size);
```

**Output:**

```text
2
```

**Why?**

Because both objects are created separately and have different references in memory.

But if we add the same object reference twice:

```javascript
let student = { name: "Rahul" };

let students = new Set();

students.add(student);
students.add(student);

console.log(students.size);
```

**Output:**

```text
1
```

**Important:** Set checks objects by reference identity, not by comparing their properties.

## 8. Important Characteristics of Set

- Set stores only unique values.
- Set maintains insertion order.
- Set does not use numeric indexes to access elements.
- Set uses `size` instead of `length`.
- Set can store numbers, strings, objects, functions and other values.
- Set uses `add()` to insert values.
- Set uses `delete()` to remove values.
- Set uses `has()` to check values.

# 2. WeakSet in JavaScript

## 1. What is WeakSet?

A `WeakSet` is a built-in JavaScript object that stores only objects and non-registered symbols as weakly held values.

In everyday beginner-level usage, remember that WeakSet is mainly used to store objects.

**In simple words:** WeakSet bhi Set ki tarah collection hai, lekin isme hum normally sirf objects store karte hain. Isme primitive values jaise numbers, strings aur booleans store nahi kar sakte.

**Important:** WeakSet does not keep its stored objects alive just because they are inside the WeakSet.

This is related to a concept called Garbage Collection.

## 2. What is Garbage Collection?

Garbage Collection is a process in JavaScript that automatically removes objects from memory when they are no longer reachable.

**Example:**

```javascript
let student = {
    name: "Rahul"
};

student = null;
```

Initially, `student` refers to an object.

After assigning `null`, the variable no longer refers to that object.

If nothing else refers to the object, it becomes eligible for garbage collection.

**Important:** Garbage collection happens automatically. We cannot force JavaScript to perform it at an exact moment.

## 3. Why do we use WeakSet?

We use WeakSet when:

- We want to store objects only.
- We want to track objects without keeping them alive just because they are in the collection.
- We want to check whether an object has already been processed.
- We want to mark objects that have a particular status.

**Real-life example:**

Suppose a website processes multiple user objects.

We want to track which users have already been verified.

We can use WeakSet to mark verified user objects.

## 4. How to Create a WeakSet?

**Syntax:**

```javascript
let myWeakSet = new WeakSet();
```

We can also pass an iterable of valid values, such as an array of objects.

```javascript
let student1 = { name: "Rahul" };
let student2 = { name: "Aman" };

let students = new WeakSet([student1, student2]);

console.log(students.has(student1));
```

**Output:**

```text
true
```

## 5. Important Methods of WeakSet

WeakSet has only three main methods:

| Method | Description |
|---|---|
| `add()` | Adds an object to the WeakSet. |
| `delete()` | Removes an object from the WeakSet. |
| `has()` | Checks whether an object exists in the WeakSet. |

### Example 1: add()

The `add()` method adds an object to the WeakSet.

```javascript
let students = new WeakSet();

let student1 = { name: "Rahul" };
let student2 = { name: "Aman" };

students.add(student1);
students.add(student2);

console.log(students.has(student1));
console.log(students.has(student2));
```

**Output:**

```text
true
true
```

**Important:** WeakSet does not accept primitive values.

```javascript
let myWeakSet = new WeakSet();

myWeakSet.add(10);
```

**Output:**

```text
TypeError
```

Because `10` is a number, not an object or non-registered symbol.

### Example 2: delete()

The `delete()` method removes an object from the WeakSet.

```javascript
let students = new WeakSet();

let student1 = { name: "Rahul" };

students.add(student1);

console.log(students.delete(student1));
console.log(students.has(student1));
```

**Output:**

```text
true
false
```

### Example 3: has()

The `has()` method checks whether an object exists in the WeakSet.

```javascript
let students = new WeakSet();

let student1 = { name: "Rahul" };
let student2 = { name: "Aman" };

students.add(student1);

console.log(students.has(student1));
console.log(students.has(student2));
```

**Output:**

```text
true
false
```

## 6. Important Concept: WeakSet Uses Object References

WeakSet checks whether the exact same object reference exists.

```javascript
let students = new WeakSet();

students.add({ name: "Rahul" });

console.log(students.has({ name: "Rahul" }));
```

**Output:**

```text
false
```

**Why?**

Because we created two different objects.

Even though both objects have the same property and value, their references are different.

**Correct Example:**

```javascript
let student = { name: "Rahul" };

let students = new WeakSet();

students.add(student);

console.log(students.has(student));
```

**Output:**

```text
true
```

## 7. Important Limitations of WeakSet

WeakSet has fewer features than Set.

| Feature | Set | WeakSet |
|---|---|---|
| Stores primitive values | Yes | No |
| Stores objects | Yes | Yes |
| `add()` | Yes | Yes |
| `delete()` | Yes | Yes |
| `has()` | Yes | Yes |
| `size` | Yes | No |
| `clear()` | Yes | No |
| `forEach()` | Yes | No |
| Iteration using `for...of` | Yes | No |
| Garbage collection friendly | No weak references | Yes, weak references |

**Why can't we iterate over WeakSet?**

Because its objects can be removed automatically by garbage collection.

If WeakSet allowed iteration, its contents could change unexpectedly depending on garbage collection.

Therefore, WeakSet does not provide:
- `size`
- `clear()`
- `forEach()`
- `keys()`
- `values()`
- `entries()`
- Iteration using `for...of`

# 3. Difference Between Set and WeakSet

| Set | WeakSet |
|---|---|
| Can store primitive values and objects. | Stores objects and non-registered symbols. |
| Holds strong references to objects. | Holds weak references to objects. |
| Supports iteration. | Does not support iteration. |
| Has a `size` property. | Does not have a `size` property. |
| Has `clear()` method. | Does not have `clear()` method. |
| Supports `forEach()`. | Does not support `forEach()`. |
| Useful for storing unique values. | Useful for tracking objects without keeping them alive solely through the collection. |

# 4. Real-Life Example: Set vs WeakSet

## Example 1: Set - Store Unique Student Names

```javascript
let students = new Set();

students.add("Rahul");
students.add("Aman");
students.add("Rahul");
students.add("Umesh");

console.log(students);
```

**Output:**

```text
Set(3) {"Rahul", "Aman", "Umesh"}
```

Here, Set stores unique student names.

## Example 2: WeakSet - Track Verified Student Objects

```javascript
let student1 = {
    name: "Rahul"
};

let student2 = {
    name: "Aman"
};

let verifiedStudents = new WeakSet();

verifiedStudents.add(student1);

console.log(verifiedStudents.has(student1));
console.log(verifiedStudents.has(student2));
```

**Output:**

```text
true
false
```

Here:
- Rahul's object is stored in WeakSet.
- Aman's object is not stored.
- We can check whether a particular object is present.

# 5. Important Interview Questions

### Q1. What is Set in JavaScript?

Set is a built-in object used to store unique values. It does not allow duplicate values.

### Q2. What is WeakSet in JavaScript?

WeakSet is a collection that weakly holds objects and non-registered symbols. In normal use, it is mainly used for tracking objects.

### Q3. What is the difference between Set and WeakSet?

Set supports primitive values and objects, iteration and the size property. WeakSet does not support primitive values, iteration or the size property.

### Q4. Does Set allow duplicate values?

No. Set stores only unique values.

### Q5. Can we store numbers and strings in WeakSet?

No. WeakSet does not accept primitive values such as numbers, strings and booleans.

### Q6. Why is WeakSet called weak?

Because it holds weak references to its objects. It does not prevent an object from being garbage-collected when there are no other strong references to it.

### Q7. Can we iterate over WeakSet?

No. WeakSet is not iterable.

### Q8. Does WeakSet have a size property?

No. WeakSet does not provide a `size` property.

### Q9. What is Garbage Collection?

Garbage Collection is the automatic process of removing objects from memory when they are no longer reachable.

### Q10. Can Set store objects?

Yes. Set can store objects, but it checks their uniqueness using object references.

### Q11. What is the difference between Set and Array?

- Array allows duplicate values.
- Set stores only unique values.
- Array supports index-based access.
- Set does not support index-based access.
