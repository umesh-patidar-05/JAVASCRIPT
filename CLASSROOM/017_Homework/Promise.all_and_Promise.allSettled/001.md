# 1. Promise.all() in JavaScript

## 1. What is Promise.all()?

`Promise.all()` is a static method of the Promise object. It is used to execute multiple promises concurrently and wait until all promises are fulfilled.

It returns a single promise that:
- Resolves when all promises are fulfilled.
- Rejects if any one of the promises is rejected.

**In simple words:** Jab hume multiple asynchronous tasks perform karne hote hain aur hume sabhi tasks ke successful results chahiye hote hain, tab hum `Promise.all()` use karte hain.

## 2. Why do we use Promise.all()?

We use `Promise.all()` when:
- We need results from multiple API calls.
- We want to run multiple asynchronous tasks concurrently.
- We want to wait until all tasks are completed successfully.
- We want to collect all successful results in one array.

**Real-life example:**

Suppose an e-commerce website needs to fetch:
1. User details.
2. Product details.
3. Order details.

Instead of waiting for each API call one by one, we can run them concurrently using `Promise.all()`.

## 3. Syntax of Promise.all()

```javascript
Promise.all([promise1, promise2, promise3])
    .then((results) => {
        console.log(results);
    })
    .catch((error) => {
        console.log(error);
    });
```

**Explanation:**
- It accepts an iterable, commonly an array of promises.
- `.then()` executes when all promises are fulfilled.
- `.catch()` executes if any promise is rejected.
- Results are returned in an array.

## 4. Examples of Promise.all()

### Example 1: Using Promise.resolve()

`Promise.resolve()` creates a promise that is already fulfilled with a given value.

```javascript
let promise1 = Promise.resolve("Apple");
let promise2 = Promise.resolve("Banana");
let promise3 = Promise.resolve("Mango");

Promise.all([promise1, promise2, promise3])
    .then((results) => {
        console.log(results);
    });
```

**Output:**

```text
["Apple", "Banana", "Mango"]
```

**Explanation:**

1. All three promises are already fulfilled.
2. `Promise.all()` waits for all promises.
3. It returns all results inside a single array.

### Example 2: Using setTimeout()

```javascript
let promise1 = new Promise((resolve) => {
    setTimeout(() => {
        resolve("Task 1 completed");
    }, 3000);
});

let promise2 = new Promise((resolve) => {
    setTimeout(() => {
        resolve("Task 2 completed");
    }, 2000);
});

let promise3 = new Promise((resolve) => {
    setTimeout(() => {
        resolve("Task 3 completed");
    }, 1000);
});

Promise.all([promise1, promise2, promise3])
    .then((results) => {
        console.log(results);
    });
```

**Output after approximately 3 seconds:**

```text
[
    "Task 1 completed",
    "Task 2 completed",
    "Task 3 completed"
]
```

**Explanation:**

1. Task 1 takes approximately 3 seconds.
2. Task 2 takes approximately 2 seconds.
3. Task 3 takes approximately 1 second.
4. All tasks start without waiting for one another.
5. `Promise.all()` waits until all three are fulfilled.

**Important:** Results maintain the same order as the input promises, not the order in which they finish.

### Example 3: What happens if one promise is rejected?

If even one promise is rejected, `Promise.all()` rejects.

```javascript
let promise1 = Promise.resolve("Task 1 completed");

let promise2 = Promise.reject("Task 2 failed");

let promise3 = Promise.resolve("Task 3 completed");

Promise.all([promise1, promise2, promise3])
    .then((results) => {
        console.log(results);
    })
    .catch((error) => {
        console.log(error);
    });
```

**Output:**

```text
Task 2 failed
```

**Explanation:**

1. Promise 1 is fulfilled.
2. Promise 2 is rejected.
3. Promise 3 is fulfilled.
4. Because one promise is rejected, the final promise returned by `Promise.all()` is also rejected.
5. Therefore, `.catch()` executes.

**Important Notes:**

- `Promise.all()` does not return partial results through its normal fulfilled result.
- It does not cancel the remaining promises when one rejects.
- Other promises may continue executing.

## 5. Real-Life Example of Promise.all()

Suppose we need to fetch three different types of data from an API.

```javascript
let userData = fetch("/api/users");

let productData = fetch("/api/products");

let orderData = fetch("/api/orders");

Promise.all([userData, productData, orderData])
    .then((responses) => {
        console.log(responses);
    })
    .catch((error) => {
        console.log("Something went wrong", error);
    });
```

**Explanation:**

- All three API requests are started.
- `Promise.all()` waits for all three requests to fulfill.
- If all succeed, we get an array of responses.
- If any request rejects, the final promise rejects.

**Note:** `fetch()` normally fulfills even for HTTP errors such as 404 or 500. We should check `response.ok` to handle those HTTP errors.

# 2. Promise.allSettled() in JavaScript

## 1. What is Promise.allSettled()?

`Promise.allSettled()` is a static method of the Promise object. It is used to wait until all promises are settled, whether they are fulfilled or rejected.

**Settled means:**
- Fulfilled (successful).
- Rejected (failed).

**In simple words:** Jab hume multiple promises ke results chahiye, chahe kuch successful hon aur kuch fail, tab hum `Promise.allSettled()` use karte hain.

## 2. Why do we use Promise.allSettled()?

We use `Promise.allSettled()` when:
- We want to wait for every promise to finish.
- We need both successful and failed results.
- One failed task should not hide the results of other tasks.
- We want to check the status of every promise.

**Real-life example:**

Suppose an e-commerce website sends notifications through:
1. Email.
2. SMS.
3. WhatsApp.

If the email fails but SMS and WhatsApp succeed, we still want to know the result of all three tasks.

Here, `Promise.allSettled()` is useful.

## 3. Syntax of Promise.allSettled()

```javascript
Promise.allSettled([promise1, promise2, promise3])
    .then((results) => {
        console.log(results);
    });
```

**Explanation:**

- It accepts an iterable, commonly an array of promises.
- It waits until every promise is settled.
- It returns an array containing the status and result of each promise.
- A rejected input promise does not make the overall `Promise.allSettled()` promise reject.

## 4. Examples of Promise.allSettled()

### Example 1: Using Promise.resolve() and Promise.reject()

```javascript
let promise1 = Promise.resolve("Apple");

let promise2 = Promise.reject("Banana failed");

let promise3 = Promise.resolve("Mango");

Promise.allSettled([promise1, promise2, promise3])
    .then((results) => {
        console.log(results);
    });
```

**Output:**

```javascript
[
    { status: "fulfilled", value: "Apple" },
    { status: "rejected", reason: "Banana failed" },
    { status: "fulfilled", value: "Mango" }
]
```

**Explanation:**

1. Promise 1 is fulfilled, so we get its value.
2. Promise 2 is rejected, so we get its reason.
3. Promise 3 is fulfilled, so we get its value.
4. All results are returned in one array.

**Important:**

For a fulfilled promise, the result object contains:

```javascript
{
    status: "fulfilled",
    value: "Apple"
}
```

For a rejected promise, the result object contains:

```javascript
{
    status: "rejected",
    reason: "Something went wrong"
}
```

### Example 2: Using setTimeout()

```javascript
let promise1 = new Promise((resolve) => {
    setTimeout(() => {
        resolve("Task 1 completed");
    }, 3000);
});

let promise2 = new Promise((resolve, reject) => {
    setTimeout(() => {
        reject("Task 2 failed");
    }, 2000);
});

let promise3 = new Promise((resolve) => {
    setTimeout(() => {
        resolve("Task 3 completed");
    }, 1000);
});

Promise.allSettled([promise1, promise2, promise3])
    .then((results) => {
        console.log(results);
    });
```

**Output after approximately 3 seconds:**

```javascript
[
    { status: "fulfilled", value: "Task 1 completed" },
    { status: "rejected", reason: "Task 2 failed" },
    { status: "fulfilled", value: "Task 3 completed" }
]
```

**Explanation:**

1. Task 1 takes approximately 3 seconds.
2. Task 2 takes approximately 2 seconds and fails.
3. Task 3 takes approximately 1 second.
4. `Promise.allSettled()` waits for all three tasks.
5. It returns the result of every promise, including the failed one.

### Example 3: Get only successful results

Sometimes we only need successful results from `Promise.allSettled()`.

We can use `filter()` and `map()` for this.

```javascript
let promise1 = Promise.resolve("Apple");

let promise2 = Promise.reject("Banana failed");

let promise3 = Promise.resolve("Mango");

Promise.allSettled([promise1, promise2, promise3])
    .then((results) => {

        let successfulResults = results
            .filter((item) => item.status === "fulfilled")
            .map((item) => item.value);

        console.log(successfulResults);
    });
```

**Output:**

```text
["Apple", "Mango"]
```

**Explanation:**

1. `Promise.allSettled()` returns all results.
2. `filter()` selects only fulfilled promises.
3. `map()` extracts their values.
4. Finally, we get only successful results.

# 3. Difference Between Promise.all() and Promise.allSettled()

| Promise.all() | Promise.allSettled() |
|---|---|
| Waits for all promises to fulfill, or rejects when one rejects. | Waits for every promise to settle. |
| Rejects if any input promise rejects. | Does not reject just because an input promise rejects. |
| Gives successful results as an array if all fulfill. | Gives status and result for every promise. |
| Does not provide partial results through its normal fulfilled result. | Provides both fulfilled and rejected results. |
| Used when all tasks must succeed. | Used when we need the result of every task. |

## 4. Visual Understanding

### Promise.all()

```text
Promise 1 → Fulfilled
Promise 2 → Fulfilled
Promise 3 → Fulfilled
                |
                ↓
       All promises fulfilled
                |
                ↓
          Final Success
```

If any one promise rejects:

```text
Promise 1 → Fulfilled
Promise 2 → Rejected
Promise 3 → Fulfilled
                |
                ↓
           Final Rejection
```

### Promise.allSettled()

```text
Promise 1 → Fulfilled
Promise 2 → Rejected
Promise 3 → Fulfilled
                |
                ↓
        Wait for all promises
                |
                ↓
       Return all results
```

# 5. Important Interview Questions

### Q1. What is Promise.all() in JavaScript?

`Promise.all()` is a static method that takes multiple promises and returns a single promise. It fulfills when all input promises fulfill and rejects if any input promise rejects.

### Q2. What is Promise.allSettled()?

`Promise.allSettled()` waits for all promises to settle, whether fulfilled or rejected, and returns their results with status information.

### Q3. What is the main difference between Promise.all() and Promise.allSettled()?

`Promise.all()` rejects if any input promise rejects, whereas `Promise.allSettled()` waits for every promise and returns the result of each one.

### Q4. Does Promise.all() maintain the order of results?

Yes. It maintains the same order as the input promises, regardless of their completion order.

### Q5. What happens if one promise fails in Promise.all()?

The promise returned by `Promise.all()` rejects, and its `.catch()` handler can handle the error.

### Q6. Does Promise.allSettled() reject if one promise fails?

No. A rejected input promise is represented as an object with `status: "rejected"` and a `reason` property.

### Q7. What are fulfilled and rejected?

- Fulfilled: Promise completed successfully.
- Rejected: Promise failed.

### Q8. What does settled mean in JavaScript promises?

Settled means a promise has reached either the fulfilled or rejected state.

### Q9. Do Promise.all() and Promise.allSettled() execute promises one by one?

No. They allow us to wait for multiple promises concurrently. The asynchronous tasks generally start when the promises are created, not when `Promise.all()` or `Promise.allSettled()` is called.

### Q10. When should we use Promise.allSettled() instead of Promise.all()?

When we need the result of every task, even if some tasks fail, we should use `Promise.allSettled()`.

# 7. Important Notes for Freshers

- `Promise.all()` is used to handle multiple promises concurrently.
- `Promise.allSettled()` waits for every promise to settle.
- `Promise.all()` rejects if any input promise rejects.
- `Promise.allSettled()` gives both successful and failed results.
- Both methods preserve the input order of results.
- `fulfilled` means successful.
- `rejected` means failed.
- `settled` means either fulfilled or rejected.
- Neither method automatically cancels other promises when one fails.

## Quick Revision

| Method | Remember |
|---|---|
| `Promise.all()` | All must succeed for the final promise to fulfill. |
| `Promise.allSettled()` | Waits for all and gives every result. |

- `Promise.all()` → Sabhi successful hone chahiye.
- `Promise.allSettled()` → Sabhi ka result chahiye, success ho ya failure.
