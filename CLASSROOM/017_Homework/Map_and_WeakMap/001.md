# 1. Map in JavaScript

## 1. What is a Map?

A `Map` is a built-in JavaScript object used to store data in the form of key-value pairs.

Each key in a Map must be unique, but values can be duplicated.

**In simple words:** Map ek collection hota hai jisme hum data ko key-value pairs mein store karte hain, just like a dictionary in Python.

**Example:**

```javascript
let student = new Map();

student.set("name", "Umesh");
student.set("age", 19);
student.set("course", "BCA");

console.log(student);
```

**Output:**

```text
Map(3) {
    "name" => "Umesh",
    "age" => 19,
    "course" => "BCA"
}
```

Here:
- `"name"` is a key.
- `"Umesh"` is its value.
- `"age"` is a key.
- `19` is its value.

## 2. Why do we use Map?

We use Map when:

- We want to store data in key-value pairs.
- We want keys of different data types.
- We want to add, update or delete key-value pairs.
- We want to maintain the insertion order of entries.
- We want to use objects, arrays or functions as keys.

**Real-life example:**

Suppose we want to store student information using their roll numbers.

```javascript
let students = new Map();

students.set(101, "Rahul");
students.set(102, "Aman");
students.set(103, "Umesh");

console.log(students.get(101));
```

**Output:**

```text
Rahul
```

Here, roll numbers are keys and student names are values.

## 3. How to Create a Map?

There are two common ways to create a Map.

### Method 1: Empty Map

```javascript
let myMap = new Map();

console.log(myMap);
```

**Output:**

```text
Map(0) {}
```

### Method 2: Map with Initial Values

We can pass an array of key-value pairs to the Map constructor.

```javascript
let student = new Map([
    ["name", "Umesh"],
    ["age", 19],
    ["course", "BCA"]
]);

console.log(student);
```

**Output:**

```text
Map(3) {
    "name" => "Umesh",
    "age" => 19,
    "course" => "BCA"
}
```

## 4. Important Methods and Properties of Map

| Method / Property | Description |
|---|---|
| `set()` | Adds a new key-value pair or updates an existing key. |
| `get()` | Returns the value associated with a key. |
| `has()` | Checks whether a key exists. |
| `delete()` | Removes a specific key-value pair. |
| `clear()` | Removes all entries. |
| `size` | Returns the total number of entries. |
| `keys()` | Returns an iterator of all keys. |
| `values()` | Returns an iterator of all values. |
| `entries()` | Returns an iterator of key-value pairs. |
| `forEach()` | Executes a function for every entry. |

### Example 1: set()

The `set()` method is used to add a new key-value pair or update an existing key.

```javascript
let student = new Map();

student.set("name", "Umesh");
student.set("age", 19);
student.set("course", "BCA");

console.log(student);
```

**Output:**

```text
Map(3) {
    "name" => "Umesh",
    "age" => 19,
    "course" => "BCA"
}
```

**Important: Updating an existing key**

```javascript
let student = new Map();

student.set("name", "Rahul");
student.set("name", "Umesh");

console.log(student);
```

**Output:**

```text
Map(1) {
    "name" => "Umesh"
}
```

**Explanation:**

- Initially, the value of `"name"` is `"Rahul"`.
- When we use the same key again, its value is updated.
- Map does not create a duplicate key.

### Example 2: get()

The `get()` method returns the value associated with a particular key.

```javascript
let student = new Map();

student.set("name", "Umesh");
student.set("age", 19);

console.log(student.get("name"));
console.log(student.get("age"));
```

**Output:**

```text
Umesh
19
```

**Important:** If the key does not exist, `get()` returns `undefined`.

```javascript
console.log(student.get("course"));
```

**Output:**

```text
undefined
```

### Example 3: has()

The `has()` method checks whether a particular key exists in the Map.

```javascript
let student = new Map();

student.set("name", "Umesh");
student.set("age", 19);

console.log(student.has("name"));
console.log(student.has("course"));
```

**Output:**

```text
true
false
```

### Example 4: delete()

The `delete()` method removes a particular key-value pair.

```javascript
let student = new Map();

student.set("name", "Umesh");
student.set("age", 19);
student.set("course", "BCA");

student.delete("age");

console.log(student);
```

**Output:**

```text
Map(2) {
    "name" => "Umesh",
    "course" => "BCA"
}
```

**Important:** `delete()` returns:
- `true` if the key existed and was deleted.
- `false` if the key did not exist.

### Example 5: clear()

The `clear()` method removes all entries from the Map.

```javascript
let student = new Map();

student.set("name", "Umesh");
student.set("age", 19);

student.clear();

console.log(student);
```

**Output:**

```text
Map(0) {}
```

### Example 6: size

The `size` property returns the total number of key-value pairs.

```javascript
let student = new Map();

student.set("name", "Umesh");
student.set("age", 19);
student.set("course", "BCA");

console.log(student.size);
```

**Output:**

```text
3
```

**Remember:** Map uses `size`, not `length`.

### Example 7: keys()

The `keys()` method returns an iterator containing all keys.

```javascript
let student = new Map([
    ["name", "Umesh"],
    ["age", 19],
    ["course", "BCA"]
]);

for (let key of student.keys()) {

    console.log(key);

}
```

**Output:**

```text
name
age
course
```

### Example 8: values()

The `values()` method returns an iterator containing all values.

```javascript
let student = new Map([
    ["name", "Umesh"],
    ["age", 19],
    ["course", "BCA"]
]);

for (let value of student.values()) {

    console.log(value);

}
```

**Output:**

```text
Umesh
19
BCA
```

### Example 9: entries()

The `entries()` method returns an iterator containing key-value pairs.

```javascript
let student = new Map([
    ["name", "Umesh"],
    ["age", 19],
    ["course", "BCA"]
]);

for (let entry of student.entries()) {

    console.log(entry);

}
```

**Output:**

```text
["name", "Umesh"]
["age", 19]
["course", "BCA"]
```

**Important:** `entries()` returns each entry as an array containing `[key, value]`.

### Example 10: forEach()

The `forEach()` method executes a callback function for every entry in the Map.

```javascript
let student = new Map([
    ["name", "Umesh"],
    ["age", 19],
    ["course", "BCA"]
]);

student.forEach((value, key) => {

    console.log(key, value);

});
```

**Output:**

```text
name Umesh
age 19
course BCA
```

**Important:** In Map's `forEach()`, the first argument is the value and the second argument is the key.

## 5. Important Concept: Map Can Use Different Data Types as Keys

Unlike normal JavaScript objects, Map allows keys of different data types.

For example:
- String
- Number
- Boolean
- Object
- Array
- Function

### Example 1: Number as a Key

```javascript
let myMap = new Map();

myMap.set(101, "Rahul");
myMap.set(102, "Aman");

console.log(myMap.get(101));
```

**Output:**

```text
Rahul
```

### Example 2: Object as a Key

```javascript
let student = {
    name: "Rahul"
};

let myMap = new Map();

myMap.set(student, "BCA Student");

console.log(myMap.get(student));
```

**Output:**

```text
BCA Student
```

**Explanation:**

Here, the complete object is used as a key.

This is one of the important features of Map.

### Example 3: Different Types of Keys

```javascript
let myMap = new Map();

myMap.set("name", "Umesh");
myMap.set(101, "Student ID");
myMap.set(true, "Active");
myMap.set({ id: 1 }, "Object Key");

console.log(myMap.size);
```

**Output:**

```text
4
```

## 6. Important Concept: Map Checks Object Keys by Reference

Two objects with identical properties are not considered the same key if they are different objects.

```javascript
let myMap = new Map();

myMap.set({ name: "Rahul" }, "Student");

console.log(myMap.get({ name: "Rahul" }));
```

**Output:**

```text
undefined
```

**Why?**

Because both objects have different references in memory.

**Correct Example:**

```javascript
let student = {
    name: "Rahul"
};

let myMap = new Map();

myMap.set(student, "Student");

console.log(myMap.get(student));
```

**Output:**

```text
Student
```

Here, we use the same object reference as the key.

## 7. Real-Life Example of Map

Suppose we want to store the marks of students using their roll numbers.

```javascript
let marks = new Map();

marks.set(101, 85);
marks.set(102, 90);
marks.set(103, 78);

console.log("Rahul:", marks.get(101));
console.log("Aman:", marks.get(102));
console.log("Umesh:", marks.get(103));
```

**Output:**

```text
Rahul: 85
Aman: 90
Umesh: 78
```

**Use case:** Map is useful when we want to store and access data using unique keys.

# 2. WeakMap in JavaScript

## 1. What is WeakMap?

A `WeakMap` is a built-in JavaScript object that stores key-value pairs where keys must be objects or non-registered symbols.

Its keys are held weakly, which means a WeakMap does not keep an object alive just because it is used as a key.

**In simple words:** WeakMap bhi Map ki tarah key-value pairs store karta hai, lekin isme keys normally objects hone chahiye. Ye objects ko weakly reference karta hai.

**Important:** Unlike Map, WeakMap does not accept primitive keys such as strings, numbers and booleans.

## 2. Why do we use WeakMap?

We use WeakMap when:

- We want to associate additional data with objects.
- We want to store private data related to objects.
- We want to avoid keeping objects alive only because they are used as keys.
- We want to store object-related information without making the collection iterable.

**Real-life example:**

Suppose we have student objects and want to store their private information separately.

We can use WeakMap to associate additional information with each student object.

## 3. What is Garbage Collection?

Garbage Collection is the automatic process through which JavaScript removes objects from memory when they are no longer reachable.

**Example:**

```javascript
let student = {
    name: "Rahul"
};

student = null;
```

Now the variable `student` no longer refers to the object.

If no other strong references exist, the object becomes eligible for garbage collection.

**Important:** WeakMap does not prevent this object from being garbage-collected merely because it is used as a key.

Garbage collection happens automatically, and we cannot predict exactly when it will happen.

## 4. How to Create a WeakMap?

**Syntax:**

```javascript
let myWeakMap = new WeakMap();
```

We can also pass an iterable containing key-value pairs.

```javascript
let student = {
    name: "Rahul"
};

let myWeakMap = new WeakMap([
    [student, "BCA Student"]
]);

console.log(myWeakMap.get(student));
```

**Output:**

```text
BCA Student
```

## 5. Important Methods of WeakMap

| Method | Description |
|---|---|
| `set()` | Adds or updates a key-value pair. |
| `get()` | Returns the value associated with a key. |
| `has()` | Checks whether a key exists. |
| `delete()` | Removes a key-value pair. |

### Example 1: set()

The `set()` method adds a new key-value pair or updates an existing key.

```javascript
let student = {
    name: "Rahul"
};

let studentDetails = new WeakMap();

studentDetails.set(student, "BCA Student");

console.log(studentDetails.get(student));
```

**Output:**

```text
BCA Student
```

**Important:** WeakMap accepts objects and non-registered symbols as keys, not ordinary primitive values.

```javascript
let myWeakMap = new WeakMap();

myWeakMap.set("name", "Umesh");
```

**Output:**

```text
TypeError
```

Because `"name"` is a string, not a valid WeakMap key.

### Example 2: get()

The `get()` method returns the value associated with a key.

```javascript
let student = {
    name: "Rahul"
};

let studentDetails = new WeakMap();

studentDetails.set(student, "BCA Student");

console.log(studentDetails.get(student));
```

**Output:**

```text
BCA Student
```

If the key does not exist, `get()` returns `undefined`.

### Example 3: has()

The `has()` method checks whether a particular key exists.

```javascript
let student1 = {
    name: "Rahul"
};

let student2 = {
    name: "Aman"
};

let studentDetails = new WeakMap();

studentDetails.set(student1, "BCA Student");

console.log(studentDetails.has(student1));
console.log(studentDetails.has(student2));
```

**Output:**

```text
true
false
```

### Example 4: delete()

The `delete()` method removes a key-value pair.

```javascript
let student = {
    name: "Rahul"
};

let studentDetails = new WeakMap();

studentDetails.set(student, "BCA Student");

console.log(studentDetails.delete(student));

console.log(studentDetails.has(student));
```

**Output:**

```text
true
false
```

## 6. Important Limitations of WeakMap

WeakMap has fewer features than Map.

| Feature | Map | WeakMap |
|---|---|---|
| Primitive keys | Yes | No |
| Object keys | Yes | Yes |
| `set()` | Yes | Yes |
| `get()` | Yes | Yes |
| `has()` | Yes | Yes |
| `delete()` | Yes | Yes |
| `size` | Yes | No |
| `clear()` | Yes | No |
| `forEach()` | Yes | No |
| `keys()` | Yes | No |
| `values()` | Yes | No |
| `entries()` | Yes | No |
| Iteration | Yes | No |
| Weak object references | No | Yes |

**Why can't we iterate over WeakMap?**

Because its keys can be removed automatically by garbage collection.

If WeakMap supported iteration, its contents could change unexpectedly depending on garbage collection.

Therefore, WeakMap does not provide:
- `size`
- `clear()`
- `forEach()`
- `keys()`
- `values()`
- `entries()`
- `for...of`

## 7. Real-Life Example of WeakMap

Suppose we have student objects and want to store additional information separately.

```javascript
let student1 = {
    name: "Rahul"
};

let student2 = {
    name: "Aman"
};

let studentDetails = new WeakMap();

studentDetails.set(student1, {
    marks: 85,
    course: "BCA"
});

studentDetails.set(student2, {
    marks: 90,
    course: "BCA"
});

console.log(studentDetails.get(student1));
console.log(studentDetails.get(student2));
```

**Output:**

```javascript
{
    marks: 85,
    course: "BCA"
}

{
    marks: 90,
    course: "BCA"
}
```

**Explanation:**

- `student1` and `student2` are objects.
- We use these objects as WeakMap keys.
- Their additional information is stored as values.
- We can access the information using `get()`.

This is useful when we want to associate extra data with objects without adding properties directly to those objects.

# 3. Difference Between Map and WeakMap

| Map | WeakMap |
|---|---|
| Stores key-value pairs. | Stores key-value pairs. |
| Keys can be primitive values or objects. | Keys must be objects or non-registered symbols. |
| Holds strong references to object keys. | Holds weak references to object keys. |
| Supports iteration. | Does not support iteration. |
| Has a `size` property. | Does not have a `size` property. |
| Has `clear()` method. | Does not have `clear()` method. |
| Supports `forEach()`. | Does not support `forEach()`. |
| Useful for general key-value storage. | Useful for associating data with objects without keeping them alive solely through the WeakMap. |

# 4. Difference Between Object and Map

JavaScript also provides normal objects for storing key-value pairs.

| Object | Map |
|---|---|
| Mainly uses strings and symbols as keys. | Supports keys of different data types. |
| Does not directly provide a `size` property. | Provides a `size` property. |
| Uses `obj.key` or `obj["key"]` to access values. | Uses `get()` to access values. |
| Uses `delete` operator to remove properties. | Uses `delete()` method. |
| Not directly iterable with `for...of`. | Directly iterable with `for...of`. |
| Useful for structured records and objects. | Useful for dynamic key-value collections. |

### Example: Object vs Map

**Using Object:**

```javascript
let student = {};

student.name = "Umesh";
student.age = 19;

console.log(student.name);
```

**Output:**

```text
Umesh
```

**Using Map:**

```javascript
let student = new Map();

student.set("name", "Umesh");
student.set("age", 19);

console.log(student.get("name"));
```

**Output:**

```text
Umesh
```

# 5. Important Interview Questions

### Q1. What is Map in JavaScript?

Map is a built-in object that stores key-value pairs. It allows keys of different data types and maintains insertion order.

### Q2. What is WeakMap in JavaScript?

WeakMap is a collection of key-value pairs where keys are objects or non-registered symbols and are held weakly.

### Q3. What is the difference between Map and WeakMap?

Map supports primitive and object keys, iteration and size. WeakMap does not support primitive keys, iteration or size.

### Q4. Can we use an object as a key in Map?

Yes. Map allows objects to be used as keys.

### Q5. Can we use a string as a key in WeakMap?

No. WeakMap does not accept ordinary primitive keys such as strings and numbers.

### Q6. What is the use of set() in Map?

The `set()` method adds a new key-value pair or updates an existing key.

### Q7. What is the difference between get() and has()?

- `get()` returns the value associated with a key.
- `has()` checks whether a key exists and returns true or false.

### Q8. Why is WeakMap called weak?

Because it holds weak references to its keys. It does not prevent an object from being garbage-collected when no other strong references exist.

### Q9. Can we iterate over WeakMap?

No. WeakMap is not iterable.

### Q10. Does WeakMap have a size property?

No. WeakMap does not provide a size property.

### Q11. What is the difference between Map and Object?

Map supports keys of different data types, has a size property and is directly iterable. Objects are commonly used for structured data and mainly use string or symbol keys.

### Q12. What is Garbage Collection?

Garbage Collection is the automatic process of removing unreachable objects from memory.
